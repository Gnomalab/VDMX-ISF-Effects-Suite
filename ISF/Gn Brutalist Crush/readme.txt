[EN] Description
A powerful hybrid glitch engine that chains XOR bitwise logic with persistent Pixel Sorting. This "Digital Alchemy" tool allows for complex data corruption aesthetics by manipulating both the color bit-structure and the spatial order of pixels.

Swappable Processing Order: Choose between XOR -> Sort or Sort -> XOR. Changing the order drastically alters the final texture, moving from "liquid data" to "shattered fibers."

Advanced XOR Logic: Total control over bit depth, block size, and individual RGB channel modulation for precise color destruction.

Hue-Based Sorting: Unlike standard sorters, this engine allows for precise selection based on color ranges (Hue), enabling targeted glitching of specific color palettes.

Persistent Feedback: Features a persistent buffer for liquid-like trails, complemented by chroma aberration, glow, and integrated dithering to prevent digital banding.

Performance Tools: Includes a "Clear Buffer" event for an instant reset during live performances.

[ES] Descripción
Un potente motor de glitch híbrido que encadena la lógica bitwise XOR con un Pixel Sorting persistente. Esta herramienta de "Alquimia Digital" permite estéticas complejas de corrupción de datos manipulando tanto la estructura de bits del color como el orden espacial de los píxeles.

Selector de Orden de Proceso: Alterna entre XOR -> Sort o Sort -> XOR. Cambiar el orden altera drásticamente la textura final, pasando de "datos líquidos" a "fibras fragmentadas".

Lógica XOR Avanzada: Control total sobre la profundidad de bits, el tamaño del bloque y la modulación individual de los canales RGB para una destrucción de color precisa.

Sorting Basado en Hue: A diferencia de los sorters estándar, este motor permite una selección precisa basada en rangos de color (Hue), permitiendo un glitch mucho más quirúrgico sobre paletas específicas.

Feedback Persistente: Utiliza un buffer persistente para crear estelas líquidas, complementado con aberración cromática, brillo (glow) y dithering integrado para evitar el banding digital.

Botón de Pánico: Incluye un evento de limpieza de buffer para un reinicio instantáneo durante sesiones en vivo.
