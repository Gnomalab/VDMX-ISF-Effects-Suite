Gn Glitch Control
[EN] Description
A versatile "Swiss-army knife" for digital glitching, offering three independent processing modules with a switchable signal path. Gn Glitch Control is designed for precise manipulation of color and spatial coordinates, allowing users to create everything from subtle chromatic aberrations to aggressive multi-copy displacements.

Three Core Modules:

Independent RGB Shift: Individual X/Y control for Red, Green, and Blue channels.

Masked Multi-copy Displacement: Generates directional "ghosting" trails based on an intelligent mask.

Axis Stretch: A coordinate-warping engine that stretches the image along the Horizontal or Vertical axis from a specific anchor point.

Switchable Processing Order: A critical feature for advanced look-dev. Choose between applying RGB shifts before the displacement (RGB > Disp) or vice versa (Disp > RGB), resulting in drastically different visual textures.

8 Masking Modes: Trigger the displacement trails using specific image properties: RGB Sum, Luminance, Hue, Saturation, Lightness, Chrominance I/Q, or Alpha.

Color Cycling: An integrated "Color Cycle" engine to offset RGB values, creating psychedelic palette shifts and solarization effects.

[ES] Descripción
Una "navaja suiza" versátil para el glitch digital, que ofrece tres módulos de procesamiento independientes con una ruta de señal conmutable. Gn Glitch Control está diseñado para la manipulación precisa del color y las coordenadas espaciales, permitiendo crear desde sutiles aberraciones cromáticas hasta desplazamientos agresivos de múltiples copias.

Tres Módulos Principales:

Desplazamiento RGB Independiente: Control individual X/Y para los canales Rojo, Verde y Azul.

Desplazamiento por Máscara (Multi-copy): Genera estelas direccionales de "fantasmeo" basadas en una máscara inteligente.

Estiramiento de Ejes (Stretch): Un motor de deformación de coordenadas que estira la imagen a lo largo del eje Horizontal o Vertical desde un punto de anclaje específico.

Orden de Procesamiento Conmutable: Una característica clave para el desarrollo de looks avanzados. Permite elegir entre aplicar los cambios de RGB antes del desplazamiento (RGB > Disp) o viceversa (Disp > RGB), lo que genera texturas visuales drásticamente distintas.

8 Modos de Máscara: Dispara las estelas de desplazamiento utilizando propiedades específicas de la imagen: Suma RGB, Luminancia, Matiz (Hue), Saturación, Ligereza, Crominancia I/Q o Alfa.

Ciclo de Color: Un motor integrado de "Color Cycle" para desplazar los valores RGB, creando cambios de paleta psicodélicos y efectos de solarización.
