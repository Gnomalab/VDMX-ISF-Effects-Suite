Gn Pixel Sorting

[EN] Description
A temporal pixel sorting engine that utilizes a persistent accumulation buffer to create infinite, evolving digital trails. The V3 introduces a "pulse" logic that allows the sorting speed to modulate rhythmically, making it an ideal tool for music-synced performances.

Persistent Accumulation: Unlike single-pass sorters, V3 builds the effect over time, allowing for much longer and more complex trails.

Cadence & Pulse: Features a rhythmic modulation engine (cadenceRate) that oscillates the sorting speed, creating a "breathing" effect that can be synced to a BPM.

Aggressive Color Fade: Integrated trail management that gradually desaturates and darkens the sorted pixels as they age, preventing the buffer from becoming a solid block of color.

Luma Range Selection: Precise control over which brightness levels trigger the effect, with an optional "Invert Selection" for targeting specific image areas.

Bi-directional Axis: Switch instantly between Horizontal and Vertical modes with a direction inversion toggle.

[ES] Descripción
Un motor de pixel sorting temporal que utiliza un buffer de acumulación persistente para crear estelas digitales infinitas y en constante evolución. La V3 introduce una lógica de "pulso" que permite modular la velocidad de ordenación rítmicamente, convirtiéndola en una herramienta ideal para actuaciones sincronizadas con música.

Acumulación Persistente: A diferencia de los sorters de una sola pasada, la V3 construye el efecto a lo largo del tiempo, permitiendo estelas mucho más largas y complejas.

Cadencia y Pulso: Incorpora un motor de modulación rítmica (cadenceRate) que hace oscilar la velocidad de ordenación, creando un efecto de "respiración" que puede sincronizarse con el BPM.

Desvanecimiento de Color Agresivo: Gestión de estelas integrada que desatura y oscurece gradualmente los píxeles ordenados a medida que envejecen, evitando que el buffer se convierta en un bloque sólido de color.

Selección por Rango de Luma: Control preciso sobre qué niveles de brillo activan el efecto, con un interruptor opcional para invertir la selección y enfocar áreas específicas.

Eje Bidireccional: Conmutación instantánea entre los modos Horizontal y Vertical con un interruptor para invertir la dirección del movimiento.
