Gn Topo Scan

[EN] Description
A high-precision topographic contour generator that transforms any video input into a technical elevation map. By treating pixel luminance as "height," it traces clean isolines that can be used for minimalist motion graphics or complex HUD (Heads-Up Display) overlays.

Integrated Pre-processing: Features a dedicated "Blur <-> Sharpen" engine. This allows you to smooth out noisy video inputs for organic curves or sharpen them for aggressive, jagged technical lines.

Temporal Erosion: Includes a speed-controlled "Erosion" effect that slides the contour levels over time, creating a hypnotic sense of organic growth or flowing terrain.

Technical Isoline Engine: Uses optimized fract() logic to generate high-frequency lines with adjustable thickness and anti-aliased softness.

HUD Composition Mode: A dedicated "Show Source" slider allows for a non-destructive overlay, mixing the generated topographic lines with the original footage for a high-tech surveillance or scanning aesthetic.

Map Inversion: Instantly flip the topography to treat shadows as peaks and highlights as valleys.

[ES] Descripción
Un generador de contornos topográficos de alta precisión que transforma cualquier entrada de vídeo en un mapa técnico de elevación. Al tratar la luminancia de los píxeles como "altura", traza isolíneas limpias que pueden utilizarse para motion graphics minimalistas o superposiciones complejas de estilo HUD (Heads-Up Display).

Pre-procesado Integrado: Cuenta con un motor dedicado de "Blur <-> Sharpen". Esto permite suavizar entradas de vídeo con mucho ruido para obtener curvas orgánicas o enfocarlas para obtener líneas técnicas agresivas y angulosas.

Erosión Temporal: Incluye un efecto de "Erosión" con control de velocidad que desplaza los niveles de contorno a lo largo del tiempo, creando una sensación hipnótica de crecimiento orgánico o terreno fluyendo.

Motor de Isolíneas Técnicas: Utiliza lógica fract() optimizada para generar líneas de alta frecuencia con grosor ajustable y suavizado (anti-aliasing).

Modo de Composición HUD: Un deslizador dedicado "Mezcla con Original" permite una superposición no destructiva, mezclando las líneas topográficas generadas con el metraje original para una estética de vigilancia o escaneo de alta tecnología.

Inversión de Mapa: Invierte instantáneamente la topografía para tratar las sombras como picos y las altas luces como valles.
