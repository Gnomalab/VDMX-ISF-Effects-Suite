Gn Pixort AE

[EN] Description
The definitive version of the PS3 temporal sorting series. This "Ultra" edition is a high-end vector-based displacement engine that treats the image as a fluid data stream, allowing for complex 360-degree digital trails with advanced persistence management.

360° Vector Control: Sort pixels in any direction using the Angle and Invert Flow controls.

8-Mode Sorting Bias: Precisely dictate the speed of the streaks based on Luma, Hue, Saturation, Lightness, Chrominance (I/Q), or Alpha.

External Mask Support: Use a secondary image input to define exactly where the sorting occurs, perfect for advanced VJ compositions.

Dynamic Fade Out: A refined buffer management system that darkens the trails over time, preventing visual "burn-in" and allowing for more rhythmic, disappearing streaks.

Chroma Aberration & Fringe: Integrated prismatic color splitting within the feedback loop and a "Fringe" lighting system that tints the edges of the sorting effect.

Blockiness & Jitter: Add texture and low-res aesthetics with the built-in mosaic and noise engine.

[ES] Descripción
La versión definitiva de la serie de sorting temporal PS3. Esta edición "Ultra" es un motor de desplazamiento vectorial de alta gama que trata la imagen como un flujo de datos fluidos, permitiendo estelas digitales complejas en 360 grados con una gestión avanzada de la persistencia.

Control Vectorial de 360°: Ordena los píxeles en cualquier dirección utilizando los controles de Ángulo e Inversión de Flujo.

Sesgo de Ordenación de 8 Modos: Dicta con precisión la velocidad de las estelas basándose en Luma, Matiz, Saturación, Ligereza, Crominancia (I/Q) o Alfa.

Soporte de Máscara Externa: Utiliza una segunda entrada de imagen para definir exactamente dónde ocurre el sorting, ideal para composiciones de VJ avanzadas.

Desvanecimiento Dinámico (Fade Out): Un sistema refinado de gestión de buffer que oscurece las estelas con el tiempo, evitando el "quemado" visual y permitiendo rastros más rítmicos que desaparecen gradualmente.

Aberración Cromática y Fringe: Separación de color prismática integrada en el bucle de feedback y un sistema de iluminación "Fringe" que tiñe los bordes del efecto de sorting.

Blockiness y Jitter: Añade textura y estética de baja resolución con el motor de mosaico y ruido integrado.
