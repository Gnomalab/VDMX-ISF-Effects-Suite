[EN] Description
A high-end feedback processor designed for complex organic trails and geometric vortex effects. This "Ultimate" version integrates edge detection as the primary source for the feedback loop, allowing for luminous, neon-like trails that react to the contours of the image.

Edge-Driven Injection: Instead of feeding back the whole image, it isolates edges and colors them using a dedicated picker, creating a clean "light paint" aesthetic.

Vortex & Transform Engine: Includes high-precision controls for Rotation (vortex), Scale (zoom), and integrated Noise Turbulence for liquid-like motion.

Chromatic Feedback: Features a built-in RGB Split (Chromatic Aberration) and a Hue Shifter that evolves the color of the trails as they age in the buffer.

Refined Composition: Offers 5 distinct Blend Modes (Mix, Screen, Overlay, Soft Light, Max) and a Luma Threshold to restrict the feedback to specific brightness ranges.

Optimized Blur: Samples multiple points within the feedback loop to create smooth, high-quality trails without sacrificing GPU performance.

[ES] Descripción
Un procesador de feedback de alto nivel diseñado para crear estelas orgánicas complejas y efectos de vórtice geométrico. Esta versión "Ultimate" integra detección de bordes como la fuente principal para el bucle de feedback, permitiendo estelas luminosas tipo "neón" que reaccionan a los contornos de la imagen.

Inyección por Bordes: En lugar de procesar toda la imagen, aísla los bordes y los coloriza mediante un selector dedicado, creando una estética de "pintura de luz".

Motor de Vórtice y Transformación: Incluye controles de alta precisión para Rotación, Escala (zoom) y una Turbulencia por Ruido integrada para generar movimiento de aspecto líquido.

Feedback Cromático: Cuenta con un RGB Split (Aberración Cromática) interno y un Hue Shifter que evoluciona el color de las estelas a medida que envejecen en el buffer.

Composición Refinada: Ofrece 5 modos de fusión distintos (Mix, Screen, Overlay, Soft Light, Max) y un Luma Threshold para restringir el feedback a rangos de brillo específicos.

Blur Optimizado: Realiza un muestreo múltiple dentro del bucle de feedback para crear estelas suaves y de alta calidad sin sacrificar el rendimiento de la GPU.
