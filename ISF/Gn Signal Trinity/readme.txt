Gn Signal Trinity

[EN] Description
The "Gn Triple Alchemy Processor" is a high-end signal routing matrix designed for advanced look development. It splits the incoming video into three distinct luminance bands (Blacks, Midtones, and Highlights) and assigns a specialized processing engine to each. With a switchable order, this shader functions like a video modular synth.

Three Integrated Engines:

Synth Modulation: A wave-based synthesis engine (from Modulation Pro) with CMYK, HSV, and RGB modes.

Radial Glitch: A multi-copy displacement tool with independent RGB position shifting.

Geometric Feedback: A temporal buffer with three modes: Linear, Zoom (infinite tunnel), and Rotation (vortex).

Dynamic Luminance Routing: Use the "Processing Order" switch to decide which engine affects which light range. For example, you can have Modulation in the shadows, Feedback in the midtones, and Glitch in the highlights.

Precision Masking: Full control over threshold points and softness for seamless transitions between the three engines.

Temporal Control: Includes an update speed frequency for the feedback loop, allowing for "stuttery" digital trails or fluid geometric motion.

Panic Button: Integrated Reset event to clear the feedback buffer instantly.

[ES] Descripción
El "Gn Triple Alchemy Processor" es una matriz de ruteo de señal de alta gama diseñada para el desarrollo de looks avanzados. Divide el vídeo entrante en tres bandas de luminancia distintas (Negros, Medios y Blancos) y asigna un motor de procesamiento especializado a cada una. Con un orden conmutable, este shader funciona como un sintetizador modular de vídeo.

Tres Motores Integrados:

Synth Modulation: Un motor de síntesis basado en ondas (heredado de Modulation Pro) con modos CMYK, HSV y RGB.

Radial Glitch: Una herramienta de desplazamiento de múltiples copias con desplazamiento de posición RGB independiente.

Geometric Feedback: Un buffer temporal con tres modos: Lineal, Zoom (túnel infinito) y Rotación (vórtice).

Ruteo Dinámico de Luminancia: Utiliza el conmutador "ORDEN" para decidir qué motor afecta a cada rango de luz. Por ejemplo, puedes ruteado la Modulación a las sombras, el Feedback a los medios y el Glitch a las altas luces.

Máscaras de Precisión: Control total sobre los puntos de umbral y el suavizado (softness) para transiciones perfectas entre los tres motores.

Control Temporal: Incluye una frecuencia de actualización para el bucle de feedback, permitiendo rastros digitales entrecortados o movimiento geométrico fluido.

Botón de Pánico: Evento de Reset integrado para limpiar el buffer de feedback instantáneamente.
