Gn Pixel Repeat
[EN] Description
A precision spatial repeat engine that uses ray-casting logic to generate rhythmic patterns and geometric trails. Instead of simply blurring or stretching, Gn Pixel Repeat searches along a directional vector to find source pixels based on a mask, repeating them across the screen with surgical accuracy.

Ray-Casting Search: High-performance 70-step search engine that identifies the source pixel along a 360° axis.

Intelligent Masking: Trigger the repetition using internal channels (Luminance, Sat x Luma, RGB) or an External Mask Layer for advanced compositing.

Repeat & Mirror: Control the length of the repeated segment and toggle Mirror (Ping-Pong) mode for seamless, fluid geometric patterns.

Override Logic: Includes a "Override When Brighter" feature that ensures the strongest part of the mask always dictates the repetition, preventing visual artifacts.

Visualization Mode: Built-in debug view to see exactly where the mask is triggering the ray-casting, essential for fine-tuning the threshold and softness.

Transparency Support: Option to output only the effect (Alpha), perfect for layering over other FX in VDMX.

[ES] Descripción
Un motor de repetición espacial de precisión que utiliza lógica de ray-casting para generar patrones rítmicos y estelas geométricas. En lugar de simplemente desenfocar o estirar, Gn Pixel Repeat busca a lo largo de un vector direccional los píxeles de origen basados en una máscara, repitiéndolos por la pantalla con precisión quirúrgica.

Búsqueda por Ray-Casting: Motor de búsqueda de 70 pasos de alto rendimiento que identifica el píxel de origen a lo largo de un eje de 360°.

Máscaras Inteligentes: Dispara la repetición usando canales internos (Luminancia, Sat x Luma, RGB) o una Capa de Máscara Externa para composiciones avanzadas.

Repetición y Espejo: Controla la longitud del segmento repetido y activa el modo Mirror (Ping-Pong) para obtener patrones geométricos fluidos y continuos.

Lógica de Anulación (Override): Incluye la función "Override When Brighter" que asegura que la parte más fuerte de la máscara siempre dicte la repetición, evitando artefactos visuales.

Modo Visualización: Vista de depuración integrada para ver exactamente dónde la máscara está activando el ray-casting, esencial para ajustar el umbral y el suavizado.

Soporte de Transparencia: Opción de salida de solo el efecto (Alpha), perfecto para apilar sobre otros FX en VDMX.
