Gn Pixel Sort Clean

[EN] Description
A refined, single-pass pixel sorting engine specifically engineered to maintain image integrity. Unlike traditional sorting algorithms that "leak" across the entire frame, Gn PixelSort Clean respects boundaries and uses a smart blending system to return to the original image.

Non-Destructive Sorting: Stops the sorting process as soon as it hits a pixel outside the defined threshold range, preventing digital "bleeding" into backgrounds or unintended areas.

4 Analysis Modes: Sort pixels based on Luma, Hue, Saturation, or Brightness.

Clean Fade Logic: Instead of fading to black, the "Fade to Original" control uses a power-curve mix to seamlessly blend the sorted streaks back into the source image.

Range Thresholding: Precise "Range Low" and "Range High" controls to isolate exactly which part of the image should be liquefied.

Organic Jitter: Integrated noise engine to break the mathematical rigidity of the sorting lines, adding a more natural, "hand-painted" digital texture.

[ES] Descripción
Un motor de pixel sorting de una sola pasada refinado, diseñado específicamente para mantener la integridad de la imagen. A diferencia de los algoritmos de ordenación tradicionales que "escapan" por todo el frame, Gn PixelSort Clean respeta los límites y utiliza un sistema de mezcla inteligente para regresar a la imagen original.

Ordenación No Destructiva: Detiene el proceso de sorting en cuanto encuentra un píxel fuera del rango de umbral definido, evitando el "sangrado" digital hacia los fondos o áreas no deseadas.

4 Modos de Análisis: Ordena píxeles basados en Luma, Matiz (Hue), Saturación o Brillo.

Lógica de Fundido Limpio: En lugar de fundir a negro, el control "Fade to Original" utiliza una curva de mezcla para integrar las estelas de forma fluida con la imagen fuente.

Umbrales de Rango: Controles precisos de "Range Low" y "Range High" para aislar exactamente qué parte de la imagen debe ser licuada.

Jitter Orgánico: Motor de ruido integrado para romper la rigidez matemática de las líneas de ordenación, añadiendo una textura digital más natural y orgánica.
