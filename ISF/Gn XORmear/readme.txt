Gn XORmear

[EN] Description
A hybrid glitch engine that merges directional smearing with bitwise logic corruption. Gn XOR Smear operates at the binary level of pixel data, creating authentic digital artifacts that range from grainy noise to monolithic blocks of corrupted color.

Bitwise Logic Corruption: Uses a manual XOR function to manipulate the 8-bit representation of RGB channels, resulting in high-contrast "data-mosh" aesthetics.

Dual-Stage Routing (The Order Factor):

XOR > Smear: Applies corruption to each sample individually before averaging, creating a textured, noisy, and high-frequency glitch.

Smear > XOR: Averages the image first and then corrupts the result, producing solid, clean blocks of "bit-crushed" color.

Luminance Band Isolation: Features a dual-threshold mask (Min/Max) to target specific light ranges, allowing you to leave highlights untouched while destroying the midtones or shadows.

360° Directional Smear: Full control over the angle and length of the trails with integrated softness to prevent hard edges.

[ES] Descripción
Un motor de glitch híbrido que fusiona el barrido direccional (smear) con la corrupción por lógica bitwise. Gn XOR Smear opera a nivel binario sobre los datos del píxel, creando artefactos digitales auténticos que van desde el ruido granulado hasta bloques monolíticos de color corrompido.

Corrupción Lógica Bitwise: Utiliza una función XOR manual para manipular la representación de 8 bits de los canales RGB, resultando en estéticas de "data-mosh" de alto contraste.

Ruteo de Doble Etapa (El factor Orden):

XOR > Smear: Aplica la corrupción a cada muestra individualmente antes de promediar, creando un glitch texturizado, ruidoso y de alta frecuencia.

Smear > XOR: Promedia la imagen primero y luego corrompe el resultado, produciendo bloques sólidos y limpios de color "bit-crushed".

Aislamiento de Bandas de Luma: Cuenta con una máscara de doble umbral (Min/Max) para enfocar rangos de luz específicos, permitiendo dejar las luces intactas mientras se destruyen los medios tonos o las sombras.

Barrido Direccional de 360°: Control total sobre el ángulo y la longitud de las estelas con suavizado integrado para evitar bordes duros.
